# TangoNest

単語の収集・整理・復習・Quiz・Listenを備えたアプリです。現在の公開ビルドは `1.0.0-rc.19-fdg20`。2026-10-14にピンイン管理とQuiz Skipの改善を公開しました。公開状態はGitHub Pagesの成功したデプロイと公開ハッシュで確認してください。

Typingは未設定時にBack → Frontで始まり、形式ごとに明示した方向を保持します。入力へ自動フォーカスし、Enterで採点・次問へ進めます。SkipはWrongとして記録し、学習更新・正答率・Retry Mistakesに含めます。復習には回答時点の問題・自分の回答・正答・例文を表示し、音声・保存・詳細を操作できます。Retry Mistakesは今回の誤答だけ、Continue Quizは元の設定で現存する対象単語を抽出し、問題順をシャッフルして開始します。自動進行は正誤共通の2秒で、音声終了・一時停止・手動操作の制御も保持します。

開発はこのGitリポジトリに集約します。[開発・ビルド・配布手順](DEVELOPMENT.md)と[整合性調査・Quiz実装計画](docs/RUNTIME_RECONCILIATION.md)を参照してください。

```sh
npm ci
npm run dev
```

`http://127.0.0.1:4173/` で確認できます。`npm test` は編集元と実行用ファイルの一致も検証します。ソース変更後は `npm run build` が必要です。`app.js`等が編集元で、HTMLが読む`*-rc19-fdg1`は生成物です。全12組は `tools/runtime-pairs.json` に記載しています。英語UIの `locales/base.js` も `locales/en.json` とレジストリからビルドで生成し、一致を検査します。

本番への接続設定は公開可能なSupabaseキーのみです。秘密キーを追加しないでください。既存のユーザーデータ、Auth、同期、PWA更新動作を保持します。ローカルのブラウザテストは隔離したデータを使います。

ルートのSQLや過去のリリース報告書は履歴として保存されています。アプリ更新のためにSQLやデータリセットを実行しないでください。PagesはGitHub Actionsの手動公開ワークフローで、抽出済みの成果物だけを配信します。本番公開にはユーザーの明示的な許可が必要です。

## ピンイン・Quiz Skip改善の公開版

`1.0.0-rc.19-fdg19` を本番公開しました。Edit Wordの任意ピンイン入力、中国語一覧・Quiz解答後の表示、SkipをWrongとして集計・再挑戦する処理を追加しています。本番66ファイルと18スクリプトの一致を確認済みです。[公開確認報告](docs/deploy-pinyin-skip-2026-10-14.md)を参照してください。変更ファイル・データ保護・検証結果は [改善報告](docs/pinyin-skip-2026-10-14.md) を参照してください。

## 中国語文型の読み上げ

FDG20では中国語の音声合成直前に「～」「〜」「~」をスペースへ変換し、表示用の原文を保持します。[公開確認報告](docs/deploy-chinese-pattern-2026-10-14.md)を参照してください。Chineseのデータ修正候補43単語は承認済みですが、ユーザーの希望で実データ更新を後日へ延期しています。
