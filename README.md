# TangoNest

単語の収集・整理・復習・Quiz・Listenを備えたアプリです。公開中の実行コードは `1.0.0-rc.19-fdg16`。2026-10-11に、公開内容を変えずにGit管理下の編集元と読み込み先を整合させました。

開発はこのGitリポジトリに集約します。[開発・ビルド・配布手順](DEVELOPMENT.md)と[整合性調査・Quiz実装計画](docs/RUNTIME_RECONCILIATION.md)を参照してください。

```sh
npm ci
npm run dev
```

`http://127.0.0.1:4173/` で確認できます。`npm test` は編集元と実行用ファイルの一致も検証します。ソース変更後は `npm run build` が必要です。`app.js`等が編集元で、HTMLが読む`*-rc19-fdg1`は生成物です。全12組は `tools/runtime-pairs.json` に記載しています。

本番への接続設定は公開可能なSupabaseキーのみです。秘密キーを追加しないでください。既存のユーザーデータ、Auth、同期、PWA更新動作を保持します。ローカルのブラウザテストは隔離したデータを使います。

ルートのSQLや過去のリリース報告書は履歴として保存されています。アプリ更新のためにSQLやデータリセットを実行しないでください。Pagesは現在main直下を配信する設定なので、公開承認前にmainへpushしないでください。今回のブランチはローカルのみです。
